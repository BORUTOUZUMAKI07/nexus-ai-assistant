# Nexus AI Assistant — Frontend

The Next.js **16.3.4** (App Router) + **React 19.2.8** chat client for Nexus AI
Assistant. It proxies every backend call through BFF-style route handlers:
the browser talks to `localhost:3000`, and `src/app/api/**/route.ts` forwards
to the FastAPI backend (`localhost:8000`) with credentials/cookies attached.

## At a glance

- **Pages**: landing (`src/app/page.tsx`), SSO sign-in (`src/app/signin/`),
  the main app shell (`src/app/app/page.tsx` — sidebar + chat + views).
- **Core components** (`src/components/`): `ChatArea`, `ChatInput` (slash
  commands, audio capture, file attach), `CommandPalette` (⌘K), `Sidebar`,
  `ArtifactCanvas` (find/save keyboard shortcuts), `KnowledgeView` (RAG),
  `SettingsView` (BYOK keys, memories, appearance), `UsageView`,
  `AdminView`, `PlanHistory`, `AuthModal`, `CitationInspector`.
- **State/hooks**: `hooks/useNexusChat.ts` drives the chat (SSE via
  `POST /api/v1/conversations/{conversation_id}/messages/stream`).
- **BFF proxy**: route handlers in `src/app/api/**` forward via the shared
  helper in `src/lib/proxy.ts` (reads the JWT cookie → `Authorization: Bearer`
  header); `src/proxy.ts` is the edge middleware that server-side-gates `/app`.
  Backend address resolution: `BACKEND_URL` → legacy `NEXT_PUBLIC_API_URL` →
  `http://127.0.0.1:8000`.
- **Stack**: Next 16.3.4 · React 19.2.8 · TypeScript 5 · Tailwind 4 ·
  Radix UI + `cmdk` · `lucide-react` · `motion` · `sonner` · Vitest 4 ·
  Playwright · MSW (test mocking).

> **Note:** `frontend/AGENTS.md` (auto-generated by `next dev`) warns that this
> Next.js has breaking changes vs. older training data. Read
> `node_modules/next/dist/docs/` before writing Next-specific code, and run
> `npx next typegen` before `tsc --noEmit` (CI does this — `LayoutProps` /
> `PageProps` are generated globals).

## Getting started

```bash
npm install
npm run dev          # http://localhost:3000
```

The backend must be running (`make backend` from the repo root, or see
[`../backend/README.md`](../backend/README.md)). Local infra (Postgres, Redis,
Qdrant, MinIO) comes from `docker compose up -d` at the repo root.

To point at a non-default backend, set `BACKEND_URL` in `.env.local` (a
legacy `NEXT_PUBLIC_API_URL` is also honored; fallback is
`http://127.0.0.1:8000` — see `src/lib/proxy.ts`).

## Testing

- **Unit**: 25 Vitest files under `src/test/` — components, hooks (`useNexusChat`),
  lib (`api`, `auth`, `proxy`, theme), BFF route handlers, plus cross-tab
  refresh and API-parity/wiring suites. MSW mocks live in `src/test/mocks/`.
- **E2E**: Playwright specs in `frontend/e2e/` (`*.spec.ts`).
- CI runs `next typegen` → `tsc --noEmit` → `eslint` → `vitest` → `next build`.

## Keyboard shortcuts (the ones that actually exist)

| Shortcut | Where | Effect |
|---|---|---|
| `⌘K` / `Ctrl+K` | anywhere | toggle command palette |
| `⌘F` / `Ctrl+F` | artifact canvas | find in artifact |
| `⌘S` / `Ctrl+S` | artifact canvas, while editing | save the edit |
| `Esc` | artifact canvas / slash menu | close search, abandon edit, dismiss menu |
| `↑`/`↓`/`Tab`/`Enter` | chat input (slash menu open) | navigate/apply slash command |
| `Enter` | chat input | send (Shift+Enter inserts a newline) |

Verified against `src/components/CommandPalette.tsx:68`,
`src/components/ArtifactCanvas.tsx:92,97,108`, and
`src/components/ChatInput.tsx:117-137`. Nothing else is bound.
