# Nexus AI Assistant — Keyboard Shortcuts Reference

| Shortcut | Action | Scope |
|---|---|---|
| `Ctrl + Enter` / `Cmd + Enter` | Submit message | Chat input |
| `Shift + Enter` | New line | Chat input |
| `Ctrl + K` / `Cmd + K` | Quick search conversations | Global |
| `Ctrl + Shift + O` | Open new conversation | Global |
| `Ctrl + Shift + B` | Toggle sidebar navigation | Global |
| `Ctrl + Shift + C` | Toggle Code Execution Mode | Chat input |
| `Ctrl + Shift + W` | Toggle Web Search Mode | Chat input |
| `Esc` | Close active modal / Stop generation | Global / Streaming |
| `Ctrl + /` | Open keyboard shortcuts help modal | Global |
